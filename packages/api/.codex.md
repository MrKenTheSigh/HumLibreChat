## Codex Notes

- `api/server/routes/**/*.js` 透過 `require('@librechat/api')` 讀的是 `packages/api/dist/index.js`，不是 `packages/api/src`。
- 如果在 `packages/api/src` 新增或修改 export，例如新增 admin handler，source 改完後必須重跑：
  - `cd /home/dev/work/HumLibreChat/packages/api && npm run build`
- 若沒重 build，backend 重啟後可能出現這類錯誤：
  - `TypeError: argument handler must be a function`
- 這代表 route 已經引用了新名稱，但 `dist` 還是舊版，`require('@librechat/api')` 取到的是 `undefined`。
