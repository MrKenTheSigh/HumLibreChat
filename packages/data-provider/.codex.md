## Codex Notes

- 前端與 client hooks 使用的 `librechat-data-provider` 來自 `packages/data-provider/dist/index.js`，不是 `packages/data-provider/src`。
- 如果在 `src/data-service.ts`、`src/api-endpoints.ts`、`src/types/*` 新增或修改 export，例如新增 `dataService.updateAdminUser`，source 改完後必須重跑：
  - `cd /home/dev/work/HumLibreChat/packages/data-provider && npm run build`
- 若沒重 build，瀏覽器端可能出現這類錯誤：
  - `dataService.updateAdminUser is not a function`
- 這代表 mutation / hook 已經改了，但前端實際載入到的 package 輸出仍是舊版。
