# Backlog Notes

This directory is for future work that is intentionally not scheduled into an active phase yet.

Typical contents:

- validation and verification follow-ups
- research notes
- operational notes
- deferred architecture work

UI/UX plans that become their own structured workstream should move to `../ui-ux/` instead of staying mixed into backlog notes.

These notes should stay independent from the phase plans until they are concrete enough to be pulled into a numbered phase.
