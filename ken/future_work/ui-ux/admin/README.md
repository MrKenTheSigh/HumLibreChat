# Admin UI/UX Notes

This directory centralizes admin-console UI and UX planning documents.

## Current Documents

- `admin-ui-ux-plan.md`
  Overall UI/UX workstream plan for the admin console.
- `admin-ui-ux-batch-1-spec.md`
  Batch 1 execution spec for admin shell, users, and roles.
- `admin-user-provisioning-ui-spec.md`
  User-detail provisioning UI spec that was originally planned under Phase 4.
- `admin-usage-dashboard-ui-spec.md`
  Usage dashboard UI spec that was originally planned under Phase 5.
- `admin-users-auth-source-note.md`
  Note on removing the misleading `provider` filter from the Users page and how to reintroduce it later as an auth-source concept.
- `admin-ui-ux-guidelines.md`
  The cross-page UI/UX rules distilled from the Users redesign and intended to guide the rest of the admin console.
- `admin-i18n-zh-hant-plan.md`
  Batch plan for bringing the current Admin Console copy to English plus Traditional Chinese without doing one risky bulk localization pass.

These files are grouped here because they are all front-end/admin-surface documents, even when their implementation touched different numbered phases.
