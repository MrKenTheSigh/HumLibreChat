# UI/UX Notes

This directory groups UI and UX planning documents that should stay together even when the implementation work spans multiple admin phases.

## Structure

- `admin/`
  Admin console UX planning, batch specs, and page-level UI specs.
- `zh-hant-localization-fallback-note.md`
  Cross-surface note on Traditional Chinese fallback gaps, mixed-language UI symptoms, and the need for a broader `zh-Hant` coverage pass.

Use this directory when the main concern is interface clarity, interaction safety, information architecture, or workflow readability rather than backend capability.
